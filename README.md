Para poder ejecutar el programa correctamente sigue los siguentes pasos

1. Primero importa los archivos .csv con el nombre de "preguntas_seguros_" y "resultados".
2. Una ves que fueron importadas ejecuta el primer Script en el cual se ingresara el nombre del alumno, y comensara el cuestionario
3. El cuestionario cuenta con un total de 10 preguntas que se dividen en dos tipos de opcion multiple y de seleccion multiple
4. Para el opcion multiple escriba una respuesta del 1 al 3
5. Para el de selección multiple escoge una respuesta coloca una coma (,) y tu siguiente respuesta las veses que creas correctas Ej. (1, 3)
6. Una ves completes las 10 preguntas te dara tu calificación y la opcion de repetir el examen, contando con un total de 3 intentos.
7. Si deseas volver a realizarlo el examen empesara de nuevo con otra 10 preguntas que pueden llegar a cambiar
8. El examen guardarala calificacion mas alta, una ves que estes conforme con tu calificacion o se terminen tus intentos los resultados se guardaran en el archivo resultados.csv
9. Una ves que todos los alumnos lleguen a realizar el examen y esten guardados en el archivo resultados.csv ejecute el segundo Script, el cual generara el Reporte estadistico
